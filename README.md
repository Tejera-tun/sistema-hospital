# Sistema Hospital

Sistema web para la gestión de información hospitalaria y almacenamiento de respuestas sobre las encuestas.

## Descripción

Este sistema permitirá una mayor accesibilidad de datos a los pacientes de la clínica mediante el escaneo de un código QR . 
También albergará un sistema de guardado de respuestas sobre las encuestas relacionadas con el sistema hospitalario y 
su relación con el cliente.
